# AGENTS.md

These instructions apply to this project.

- Keep the project skill-first and local-first.
- Do not include private writing samples, OAuth tokens, API keys, or scraped social content in commits.
- Verify Spiral MCP configuration with `codex mcp list` or `codex mcp get spiral` before claiming it is installed.
- Treat the Spiral web app as the source of truth for UI behavior when docs and live product differ.
- Keep README claims honest: this project packages a Codex workflow for Spiral's MCP and writing-style workspace, not an official Spiral SDK.
- When adding docs, prefer concrete commands, short examples, and reproducible checks.
